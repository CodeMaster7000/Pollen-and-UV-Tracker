# Pollen and UV Tracker

## About

A Python program to display pollen count and UV levels for cities across the world, with no API key needed.

NOTE: Data retrieved from this program is not a substitute for medical advice. Open-Meteo’s pollen forecasts primarily use European CAMS coverage, so cities outside the covered region may show pollen as unavailable even when UV data works.

## Instructions for Use

Run `python pollen_uv_tracker.py` in a terminal if you have Python 3.
